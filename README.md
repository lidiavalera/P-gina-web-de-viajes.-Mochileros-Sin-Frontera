Plataforma de Venta de Viajes Inclusiva - Interfaces de Usuario (UC3M)Este proyecto consiste en el diseño y desarrollo de una página web para la venta de packs de viajes a diferentes destinos turísticos. Fue desarrollado como caso práctico para la asignatura de Interfaces de Usuario de la Universidad Carlos III de Madrid. El enfoque principal del desarrollo ha sido la creación de una plataforma altamente accesible que se adapte a las distintas necesidades de los usuarios.   🚀 Funcionalidades PrincipalesAccesibilidad e Inclusión: Incorpora un filtro de daltonismo que modifica los colores a tonos amarillos y azules, y un modo oscuro para usuarios con sensibilidad a la luz.   Internacionalización: Soporte para cambio de idioma entre español e inglés, y un sistema de conversión de divisas (euro, dólar estadounidense, yen japonés).   Gestión de Usuarios: Sistema de registro e inicio de sesión seguro, panel de perfil, y una "lista de deseos" donde los usuarios pueden guardar sus destinos favoritos.   Búsqueda y Filtros: Buscador integrado (patrón J1-Search Action Module) y filtros de medios de transporte basados en la ciudad de origen del usuario.   Interacción de la Comunidad: Sistema para dejar reseñas con valoraciones de 1 a 5 estrellas y una sección de consejos de la comunidad.   Proceso de Compra Optimizado: Flujo de compra diseñado con el patrón H1-ProcessFunnel para minimizar errores y pasos innecesarios.   💻 Tecnologías UtilizadasHTML5: Uso de etiquetas semánticas para mejorar la accesibilidad y el posicionamiento.   CSS3: Implementación de Flexbox para la maquetación, transiciones para suavizar cambios visuales, y Variables CSS para la gestión dinámica de los temas (Claro, Oscuro, Daltónico).   JavaScript (Vanilla): Uso de Módulos (.mjs) para estructurar el código, y LocalStorage para la persistencia de datos (sesión y preferencias).   Recursos adicionales: Google Fonts y archivos JSON para la estructuración de datos.   📐 Arquitectura y Patrones de DiseñoEl código JavaScript se ha estructurado utilizando varios patrones de diseño avanzados para garantizar su escalabilidad y mantenimiento:Patrón Módulo (Module Pattern): Para encapsular código y evitar contaminar el espacio global.   Patrón Singleton: Implementado con LocalStorage para mantener el estado global de la aplicación (sesión de usuario y tema visual).   Patrón Observador: Uso de EventTarget.addEventListener para reaccionar a las interacciones del usuario.   Patrón Factory: Utilizado junto a document.createElement para generar dinámicamente elementos de la interfaz.   📊 Usabilidad y EvaluaciónEl desarrollo se guio por las heurísticas de usabilidad (visibilidad del estado del sistema, prevención de errores, control del usuario, etc.). Para garantizar la calidad final del producto, se realizaron dos evaluaciones:   Auditoría de Accesibilidad: Se superaron las pruebas con la herramienta WAVE, corrigiendo errores de contraste, etiquetas (labels) en formularios y textos alternativos (alt) en imágenes.   Evaluación SUS: Se realizó un cuestionario de usabilidad (System Usability Scale) con usuarios reales, obteniendo una puntuación de excelencia de 83.7.
